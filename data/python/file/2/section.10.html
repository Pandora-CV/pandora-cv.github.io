for循环

学习目标:

  1. 掌握for循环语句的使用

for循环和while循环很相似, 学习for循环可以类比while循环,二者都可以完成循环功能.

for循环的格式

for 临时变量 in 列表或者字符串等可迭代对象:
    循环满足条件时执行的代码

demo1

name = 'itheima'

for x in name:
    print(x)

运行结果如下:

i
t
h
e
i
m
a

demo2

name = "hello"
for x in name:
   print(x)
   if x == 'l':
     print("Hello world!")

运行结果如下:

h
e
l
Hello world!
l
Hello world!
o

demo3

# 作为刚开始学习python的我们，此阶段仅仅知道range(5)表示可以循环5次即可
for i in range(5):
    print(i)

'''
效果等同于 while 循环的：

i = 0
while i < 5:
    print(i)
    i += 1
'''

运行结果如下:

0
1
2
3
4
